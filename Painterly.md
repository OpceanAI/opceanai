# Painterly Editorial Design + Neo-Vintage / Modern Retro
## A Master Style Guide for OpceanAI.com

This document is a **visual and product-direction specification** for building **OpceanAI.com** in a style that blends:

- **Painterly Editorial Design**
- **Neo-Vintage / Modern Retro**
- **Liquid Glass**
- **Frutiger Aero atmosphere**
- **Modern answer-engine clarity** inspired by Perplexity / Comet

The goal is not to make the site look "old" in a generic way.  
The goal is to make it feel like:

> **a beautiful, art-directed digital publication that happens to be an intelligent product.**

It should feel like a website that was carefully composed, emotionally resonant, tactile, slightly nostalgic, and deeply polished.

---

# 1. Core Design Thesis

OpceanAI.com should feel like **technology presented as a living editorial artifact**.

That means:

- the page should feel **curated**, not cluttered
- visuals should feel **painted**, not sterile
- the layout should feel **designed like a magazine cover and a gallery wall at the same time**
- motion should be **slow, graceful, and intentional**
- materials should feel **soft, glassy, layered, and luminous**
- the interface should be **modern in behavior**, but **artful in atmosphere**

This is the space between:
- a product landing page
- an art publication
- a nostalgic web collage
- a glossy future interface

The result should feel like:
- **a painterly portal**
- **a calm intelligence engine**
- **a modern retro object**
- **a soft-glass editorial landscape**

---

# 2. Style Definition

## 2.1 Painterly Editorial Design

“Painterly Editorial Design” means:

- backgrounds that resemble painted canvases, watercolor washes, scanned paper, or soft gradients
- compositions that behave like magazine spreads
- large typographic hierarchy
- strong use of negative space
- image-led storytelling
- visual rhythm created by text/image alternation
- content that looks **art-directed**, not auto-generated

The design should suggest:
- brushstrokes
- pigment
- paper fibers
- ink bleed
- faded print
- soft color transitions
- a human-made touch

The style should not become messy.  
Painterly does **not** mean noisy.  
Painterly means **tactile**.

## 2.2 Neo-Vintage / Modern Retro

Neo-vintage means the site borrows the emotional language of older design eras, but with modern usability.

This includes:
- soft muted colors
- warm neutrals
- washed blues and moss tones
- analog texture
- subtle retro typography choices
- graceful spacing inspired by print
- an atmosphere that feels “rediscovered”

It should never become:
- kitsch
- faux-1990s gimmickry
- novelty retro
- heavy grunge

It should feel like:
> a contemporary interface that remembers older media.

## 2.3 Liquid Glass

Liquid Glass adds:
- translucent surfaces
- refractive panels
- layered depth
- soft highlights
- subtle blur
- physically believable glass-like edges
- moving light across components

Used correctly, Liquid Glass should make the interface feel:
- luminous
- premium
- alive
- almost aquatic

Used incorrectly, it becomes:
- muddy
- hard to read
- over-shiny
- decorative without function

For OpceanAI, Liquid Glass should be used to support the editorial feel, not overpower it.

## 2.4 Frutiger Aero Atmosphere

Frutiger Aero contributes:
- open skies
- aqua and ocean tones
- cleanliness
- optimistic futurism
- bubbles, light, and fluidity
- the feeling of a bright ecological future

Use this as a **mood layer**, not a literal decoration layer.

Do:
- water-like gradients
- airy bubbles
- transparent orb motifs
- luminous blue-green highlights
- soft environmental glow

Do not:
- overload with fish, leaves, or clichés
- turn the site into a nostalgia museum
- use too many literal stock-photo references

# 3. Visual Principles

## 3.1 The page must feel composed, not assembled

Every section should appear intentionally placed.  
Nothing should feel like a default template.

The visual system should obey:
- alignment
- rhythm
- breathing room
- consistent spacing
- restrained ornamentation

## 3.2 The page must feel like a publication

Treat the homepage like:
- a cover
- an opening spread
- an editorial feature
- a visual statement

Not like:
- a dashboard
- a landing page with too many CTAs
- a generic SaaS home

## 3.3 The page must feel like a material object

The interface should have:
- depth
- grain
- light
- edge softness
- transparency
- layered contrast

The screen should feel like a surface with atmosphere.

## 3.4 The page must feel emotionally calm

The user experience should be:
- quiet
- intelligent
- spacious
- elegant
- confident

The page should never shout.

# 4. Color System

The color palette should behave like **washed pigment plus glass light**.

## 4.1 Primary palette directions

Use one of two main modes:

### Light mode
- parchment white
- warm fog
- pale sky
- milky aqua
- dusty blue
- muted green

### Dark mode
- deep ink blue
- ocean black
- midnight teal
- luminous cyan highlights
- soft frosted white

## 4.2 Recommended palette families

### Painterly neutrals
- `#F5F1E8` — parchment
- `#EAE3D7` — paper gray
- `#D8D1C3` — warm stone
- `#B8AFA0` — dry clay

### Neo-vintage blues
- `#7FA9C9` — faded sky
- `#5F88B2` — museum blue
- `#3C6F97` — archival blue
- `#214F72` — deep washed navy

### Frutiger aqua / glass tones
- `#A7F0E5` — mist aqua
- `#76E4D6` — bright water
- `#4FBFD2` — aqua glass
- `#C9FBFF` — white aqua

### Botanical / organic accents
- `#A9C88E` — soft moss
- `#7FA86E` — muted leaf
- `#D8D2A2` — warm sage
- `#B5D9B0` — washed mint

### Editorial accent tones
- `#9A6E63` — clay rose
- `#A57C5B` — dried sienna
- `#6E5B7A` — dusty plum
- `#C07D63` — terracotta paper

## 4.3 Color behavior rules

- Avoid pure black unless it is a deliberate dark-mode anchor.
- Avoid oversaturated neon.
- Avoid cold corporate blue as the only accent.
- Avoid flat gray-on-white monotony.
- Let backgrounds fade into each other.
- Let accent colors appear as light, not as blocks.

## 4.4 Gradient guidance

The gradients should feel like:
- sky at dawn
- watercolor wash
- glass reflecting light
- shallow water over sand
- paper stained by pigment

Recommended gradients:
- blue → aqua → white
- parchment → pink-gray → warm cream
- midnight blue → teal → pale cyan glow
- moss → mist → sky

# 5. Typography System

Typography is one of the most important parts of this style.

The type should feel:
- editorial
- cultured
- soft
- legible
- slightly literary
- modern, but not robotic

## 5.1 Typography philosophy

Use typography to create:
- hierarchy
- atmosphere
- pacing
- authority
- calm

The type should not be:
- too geometric
- too futuristic
- too “startup product”
- too compressed
- too sterile

## 5.2 Recommended type categories

### Display serif
For hero headings, large quotes, section openers, and emotional titles.

Characteristics:
- high contrast
- elegant curves
- modern classic feel
- art publication energy

Possible choices:
- Cormorant Garamond
- Fraunces
- Playfair Display
- Libre Baskerville
- a premium serif with editorial presence

### Body text
For readable descriptions, product copy, and explanatory blocks.

Possible choices:
- Inter
- Source Sans 3
- IBM Plex Sans
- Work Sans
- system UI sans

### Technical mono
For:
- labels
- code snippets
- metadata
- small system notes
- link labels

Possible choices:
- IBM Plex Mono
- JetBrains Mono
- Space Mono
- SF Mono-like fallback stack

## 5.3 Type sizing philosophy

Large screens should feel airy.

Suggested scale:
- Hero heading: `clamp(3.5rem, 8vw, 8rem)`
- Section heading: `clamp(1.5rem, 2.8vw, 3rem)`
- Body text: `16px–20px`
- Supporting text: `13px–15px`
- Micro labels: `11px–12px`

## 5.4 Line height and spacing

For editorial calm:
- body line-height: `1.55–1.8`
- headings: `0.9–1.08`
- captions: `1.3–1.45`

Never make text feel crowded.

## 5.5 Letter spacing

Use letter spacing very carefully:
- small uppercase labels: slightly wider tracking
- hero headlines: almost none
- body text: normal
- technical labels: modest tracking

Avoid aggressive tracking, because it destroys the softness.

# 6. Layout System

## 6.1 General layout model

The layout should feel like an editorial homepage:
- a powerful hero
- a clear content rhythm
- structured sections
- asymmetry with intention
- large fields of breathing room

## 6.2 Grid

Use a flexible editorial grid:
- 12-column desktop base
- 6-column tablet base
- 4-column mobile base
- large outer margins
- generous gutters

The site should feel framed, not stretched edge-to-edge.

## 6.3 Composition patterns

Good patterns for this style:
- centered hero with floating visual layers
- left-aligned editorial blocks
- alternating text and image rows
- asymmetric cards
- full-bleed image bands with overlaid captions
- split-screen compositions
- narrow reading columns for explanatory copy

## 6.4 Spacing rules

Spacing is crucial.

Suggested increments:
- 4px base unit
- 8px rhythm
- 16px system spacing
- 24px section spacing
- 32px major spacing
- 48px+ for dramatic breathing room

Avoid cramped areas.  
A painterly editorial site should feel like it has air between thoughts.

# 7. Material Language

## 7.1 Paper

Paper should be implied through:
- background texture
- subtle grain
- soft edge fades
- off-white surfaces
- archival framing

It can feel:
- scanned
- printed
- slightly aged
- tactile

## 7.2 Glass

Glass should be implied through:
- translucency
- blurred backdrops
- specular highlights
- layered reflections
- delicate borders

Use it for:
- nav bars
- floating controls
- chips
- search bar
- popovers
- small info cards

## 7.3 Paint

Paint should be implied through:
- watercolor gradients
- pigment clouds
- brush-like shapes
- soft blobs
- atmospheric overlays

## 7.4 Noise / grain

Grain is essential.  
It keeps the design from looking too synthetic.

Use:
- subtle noise overlay
- paper texture
- low-opacity grain
- very faint film-like speckling

Do not make the grain obviously visible at normal viewing distance.

## 7.5 Patina / age

Neo-vintage surfaces can feel aged through:
- softened saturation
- slightly muted whites
- gentle chromatic variation
- imperfect texture
- a little visual weathering

This is not decay.  
This is patina.

# 8. Motion System

Motion must be:
- slow
- soft
- organic
- physically believable
- emotionally restrained

## 8.1 Background motion

Background motion can include:
- drifting light
- faint parallax
- slow particles
- liquid gradient movement
- paper shimmer
- soft glow breathing

Avoid:
- aggressive looping
- busy animated backgrounds
- fast transitions
- flashy motion gimmicks

## 8.2 Hover motion

On hover:
- increase glow gently
- shift highlight position
- raise elevation slightly
- animate the glass edge
- let content appear to float

Hover should feel like:
> moving your hand over a wet painted surface under glass.

## 8.3 Section transitions

Transitions between sections should:
- fade
- slide lightly
- cross-dissolve
- drift in
- expand softly

No hard snaps.

## 8.4 Theme transitions

If the site supports light/dark theme:
- the transition should feel atmospheric
- dark should expand from a source point
- light should bloom from a source point
- the change should affect the whole environment

This can be done as a visual expansion wave.

The hero should contain:
- OpceanAI logo or wordmark

- one primary action
- one secondary action

## 9.2 Featured modules

Below the hero, present:
- Projects
- Documentation

## 9.3 Story section

Explain what OpceanAI is:
- a research ecosystem

- a living design language

## 9.4 Featured projects

Projects should be presented with:
- a title
- a short description
- a material treatment
- a soft motion interaction

## 9.5 Footer

The footer should feel like:
- a quiet colophon

Include:
- copyright

# 10. Component Design Rules

## 10.1 Header / navigation

Navigation should:
- be minimal
- float gently over the background
- use soft translucent material
- feel stable but light

Keep navigation items limited:
- Projects
- Docs
- Research
- About

## 10.2 Search / explore bar

This is the most important interactive element after the hero.

It should feel like:
- a glass lens
- a command input
- an answer-engine search field
- a soft illuminated surface

Behavior:
- expands slightly on focus
- shows subtle inner glow
- has a calm placeholder
- feels inviting, not technical

## 10.3 Cards

Cards should not look like generic SaaS boxes.

Cards should feel like:
- editorial panels
- display tiles
- floating art plates
- glass-framed notes

Include:
- title
- short copy
- metadata
- soft hover
- subtle border glow

## 10.4 Labels and metadata

Use small labels for:
- status
- tags
- version
- date
- type
- category

Make them feel like archive labels or museum captions.

## 10.5 Call-to-action buttons

Buttons should be:
- pill-like or softly rounded
- glass-based
- airy
- readable
- gently highlighted

Avoid:
- harsh solid blocks
- heavy shadows
- neon fills
- overly loud icons

# 11. Image Direction

The imagery should mix:
- paintings
- scans
- textures
- soft landscapes
- abstract aquatic visuals
- gentle technology metaphors
- dreamy surfaces
- paper and glass overlays

## 11.1 Good image subjects

- oceans
- sky
- clouds
- mist
- light through water
- abstract paint fields
- archival paper
- reflective surfaces
- botanical fragments
- blurred digital objects

## 11.2 Bad image subjects

- generic tech stock photos
- business people in suits
- overused circuit-board visuals
- aggressive cyberpunk imagery
- dated gradients without texture
- overly literal AI robots

## 11.3 Image treatment

Images should be:
- softly color-graded
- gently desaturated or selectively saturated
- slightly grainy
- lightly blurred at edges
- integrated with the layout

---

# 12. Texture Strategy

Texture matters a lot in this style.

## 12.1 Texture types to use

- paper grain
- watercolor wash
- brushed paint
- soft halftone
- film grain
- light dust
- noisy translucency
- faint scanline texture if appropriate

## 12.2 Texture intensity

Texture should usually stay:
- 3% to 15% visible
- subtle at first glance
- noticeable on close inspection

The site should feel rich, not dirty.

## 12.3 How texture should behave

Texture should:
- sit behind content
- not interfere with readability
- animate slowly, if at all
- reinforce atmosphere

---

# 13. Accessibility Rules

This style must remain accessible.

## Must-do:
- high enough contrast for text
- clear focus states
- keyboard navigability
- motion reduction support
- readable font sizes
- no critical info conveyed only by color

## Must-avoid:
- text on busy painterly backgrounds without overlays
- low-contrast glass panels
- hover-only interactions for essential content
- motion that cannot be turned off

# 18. Example Liquid Glass Toggle Behavior

The theme toggle should feel like:
- a physical switch
- a material transition
- an atmospheric change
- a shift in ambient lighting

Behavior:
- light-to-dark: darkness expands from the toggle point
- dark-to-light: light expands inversely
- the transition should animate the background, glow, and panel opacity together

This gives the site a sense of environmental transformation.

# 19. What the Style Should Never Become

Avoid these failure modes:

## 19.1 Generic SaaS

Do not let it become:
- plain white
- gray cards
- blue CTA
- too much product density
- startup template energy

## 19.2 Excessive retro cosplay

Do not let it become:
- fake 90s “internet museum”
- overdone VHS or glitch treatment
- novelty web page parody

## 19.3 Over-glassed UI

Do not let it become:
- unreadable
- overblurred
- overly reflective
- saturated with shine

## 19.4 Flat minimalism

Do not let it become:
- sterile
- emotionless
- empty in a boring way
- indistinguishable from other AI products

# 20. Design Checklist for Every Page

Before shipping any screen, verify:

- Does it feel editorial?
- Does it feel painterly?
- Does it feel calm?
- Does it feel materially rich?
- Does it retain readability?
- Does it feel like OpceanAI and not a generic template?
- Does it balance modern clarity with atmospheric beauty?
- Does it use texture tastefully?
- Does glass enhance the content rather than obscure it?
- Does the layout leave enough breathing room?
- Does the page feel like a curated experience?

If the answer to any of these is no, simplify and refine.
