## Features

- **Authentic Windows 98 UI** - Desktop with icons, taskbar, start menu, and window management
- **Interactive Programs** - Terminal, Notepad, Calculator, Paint, Winamp, and more
- **MS-DOS Terminal** - Fully functional terminal with OpceanAI-specific commands (`yuuki`, `doki`, `okuru`, `flux`, `nhe`, `about`, `contact`)
- **Boot Sequence** - Animated startup with loading screens
- **Desktop & Mobile** - Responsive layouts for both desktop (Windows 98) and mobile (retro phone)
- **Sound Effects** - Authentic Windows 98 startup, click, and notification sounds
- **Screensavers** - Flying Windows, Mistify, Pipes 3D, Starfield
- **DOOM** - Yes, it runs DOOM

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + custom Win98 CSS
- **State Management**: Redux Toolkit
- **Animations**: Framer Motion + GSAP
- **UI Components**: Radix UI + shadcn/ui
- **Markdown**: react-markdown + remark-gfm
- **PDF**: react-pdf

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/OpceanAI/opceanai.git
cd opceanai

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Available Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |

## Terminal Commands

The MS-DOS Prompt includes these OpceanAI-specific commands:

```
yuuki     - Display Yuuki Models info
doki      - Display Doki Engine info
okuru     - Display Okuru Runtime info
flux      - Display Flux Framework info
nhe       - Display NHE Benchmark results
about     - Display OpceanAI company info
contact   - Display contact information
skills    - Display tech stack
joke      - Tell a joke
credits   - Show credits
```

Plus classic commands: `help`, `dir`, `ping`, `ipconfig`, `sysinfo`, `color`, `cls`, and more.
