# OpceanAI.com — Visual & Product Style Master Prompt

## Purpose

Design **OpceanAI.com** as a premium, calm, highly atmospheric AI homepage that blends:

- **Perplexity-like clarity**: a single obvious action, strong hierarchy, readable content, generous whitespace, and an answer-engine feeling.
- **Comet-like product confidence**: the site should feel like a modern intelligent browser/product surface, not a marketing brochure.
- **Liquid Glass behavior**: translucent layers, depth, reflection, refraction, soft highlights, and surfaces that feel alive without becoming noisy.
- **Frutiger Aero emotion**: optimistic early-2000s futurism, water, sky, air, light, gloss, and a subtle “technology meets nature” dream.

The result must feel like **a polished AI product from a brighter future**, not a generic startup landing page.

---

## Core Direction

The page should feel like:

- a calm intelligent interface
- a glass-built ocean of information
- a product that invites exploration without shouting
- a homepage that feels premium, clean, and slightly surreal
- a system where visual softness and technical confidence coexist

The design should avoid the usual modern AI-site clichés:
- dark SaaS gradients
- aggressive neon
- endless feature carousels
- loud product screenshots
- cluttered hero sections
- dense icon grids
- overdesigned corporate polish

OpceanAI.com should instead feel like a **breathing glass interface** with a quiet emotional pull.

---

## Design Philosophy

### 1. Content first, atmosphere second
The page must always keep the content legible and decisive. Visual beauty is there to support clarity, not fight it.

### 2. One primary action per screen
Every major viewport should have one dominant intent:
- ask a question
- explore projects
- read documentation
- open the system
- continue deeper

Avoid multiple competing calls to action.

### 3. Soft intelligence
The interface should feel smart, but not cold. It should feel aware, composed, and attentive.

### 4. Nature + technology
The visual language should constantly suggest:
- sky
- water
- mist
- reflection
- glass
- light
- depth
- floating surfaces

### 5. Calm futuristic optimism
The future here is not harsh, dark, or dystopian. It is clean, luminous, breathable, and strangely peaceful.

## Layout Principles

### Grid
Use a simple but sophisticated grid:
- wide central content column
- flexible side breathing room
- strong alignment
- deliberate section rhythm
- consistent spacing scale

Suggested structure:
- a centered hero area
- a short description beneath
- a primary input or prompt bar
- project tiles or modules below
- secondary content in compact but open sections
- sparse footer with minimal clutter

### Whitespace
Whitespace is not empty space. It is a material.

Use generous margins and padding:
- large top/bottom sections
- ample line spacing
- comfortable reading width
- room around glass panels
- no crowding around labels or buttons

### Hierarchy
Hierarchy should be obvious at a glance:
1. Brand / title
2. Main proposition
3. Primary action
4. Supporting explanation
5. Projects / modules
6. Secondary navigation
7. Subtle footer

### Composition
Keep the page balanced and composed:
- no chaotic asymmetry
- no overstacked cards
- no “everything everywhere” blocks
- no visual overload
- no dense sidebar behavior

## Liquid Glass Layering Rules

Liquid Glass in OpceanAI.com should not become heavy or gimmicky. It should be subtle and refined.

### Glass surfaces
Use glass panels for:
- buttons
- cards
- navigation chips
- toolbars
- search/prompt areas
- floating info panels
- expandable content modules

### Glass properties
Each glass surface should imply:
- translucency
- soft blur behind the surface
- thin luminous edge
- gentle highlight
- slight internal reflection
- depth separation from the background

### Glass behavior
Glass should react to:
- hover
- focus
- scroll position
- pointer movement
- ambient light direction

But the motion must remain restrained:
- no excessive wobble
- no silly bouncy effects
- no cartoon physics
- no distracting parallax storms

### Glass hierarchy
Not every surface should be equally strong. Establish levels:
- **Primary glass**: hero prompt, main action, key modules
- **Secondary glass**: supplementary cards, tags, small panels
- **Tertiary glass**: metadata, labels, helper text, compact controls

## Typography System

Typography should combine clarity, friendliness, and a subtle retro-future feeling.

### Primary type characteristics
- highly readable
- humanist
- clean
- rounded enough to feel warm
- not overly geometric
- not aggressively futuristic

### Suggested style direction
Use a combination of:
- a modern highly legible sans for body text
- a slightly more expressive display font for the hero
- a mono or technical accent font for metadata or system-like labels

### Typographic hierarchy
#### Display
Use for:
- OpceanAI title
- main headlines
- emotional statements

Should feel:
- elegant
- airy
- confident

#### Body
Use for:
- explanations
- paragraphs
- project descriptions
- help text

Should be:
- comfortable to read
- moderate line length
- generous line height

#### UI / metadata
Use for:
- labels
- timestamps
- system notes
- command-style fragments
- small references

Should feel:
- precise
- lightweight
- a bit technical

### Text rhythm
- Headlines should not be too tall or overly spaced.
- Body text should breathe.
- Metadata should be compact and clear.
- Avoid overly tight tracking.
- Avoid the coldness of ultra-minimal Swiss design.
- Avoid retro terminal monospace as the default for all content.

## Color System

The color palette should evoke water, sky, glass, and light.

### Primary colors
- ocean blue
- sky blue
- aqua
- cool white
- mint
- soft teal

### Support colors
- pale cyan
- glassy silver
- mist gray
- translucent white
- faint green highlights

### Recommended emotional distribution
- 50% blue-family tones
- 20% white / near-white
- 15% aqua / teal
- 10% glass reflections
- 5% accent color

### Color behavior
Colors should be:
- luminous, not saturated to the point of noise
- layered, not flat
- cool, not cold
- bright, not blinding
- optimistic, not sterile

### Background treatment
The background should usually be one of:
- sky gradient
- watery gradient
- soft blue haze
- blurred atmospheric field
- subtle particle field with depth

Avoid:
- black backgrounds as the default
- harsh neon
- high-contrast red alerts everywhere
- dense dark theme behavior

## Motion System

Motion must feel like light, not like software gimmicks.

### Motion principles
- slow
- calm
- elegant
- small in amplitude
- meaningful
- tied to meaning and attention

### Approved motion patterns
- glass surfaces drift a few pixels on hover
- highlights follow pointer movement subtly
- panels ease in with soft opacity and blur transitions
- background gradients shift slowly over time
- floating elements move with low-frequency motion
- section reveals happen with gentle vertical easing
- cards expand with minimal, confident animation

### Forbidden motion patterns
- bounce-heavy animations
- overshoot everywhere
- noisy looping motion
- rapid spinning elements
- playful cartoon transitions
- flashy particle explosions

### Motion personality
Motion should feel like:
- liquid moving through glass
- air pressure shifting gently
- light sliding over polished surfaces
- a system that is alive but disciplined

## Component Design Rules

### 1. Primary search / prompt module
This is the most important interface element on the page.

It should feel like:
- an invitation
- a command surface
- an exploration input
- an intelligent gateway

Required characteristics:
- large enough to be unmistakable
- visually centered or near-centered
- glassmorphic
- easy to focus
- with crisp placeholder text
- with one very clear action button

### 2. Project cards
Project cards should resemble floating glass capsules.

Each card should include:
- name
- short description
- category / role
- optional status
- subtle icon or glyph
- action hint

Cards should feel:
- clickable
- premium
- balanced
- open, not cramped

### 3. Navigation
Navigation should be minimal and calm.

Possible nav items:
- Projects
- Docs
- System
- About
- Explore

Navigation rules:
- keep it short
- make it visually light
- avoid giant menus
- avoid deep nested navigation on the landing page

### 4. Footer
Footer should be minimal:
- small type
- low visual weight
- subtle system note
- copyright or timestamp
- minimal social / repository links

## Responsive Behavior

The design should adapt elegantly across screen sizes without losing the atmosphere.

### Desktop
- primary experience
- widest use of glass layers
- full hero composition
- multi-column project display
- rich background depth

### Tablet
- reduce complexity slightly
- preserve hero presence
- collapse multi-column sections into fewer columns
- maintain spacing generously

### Mobile
- preserve hierarchy
- keep the prompt/search module prominent
- reduce decorative background intensity
- stack cards vertically
- simplify glass overlays to remain readable
- keep tap targets large and comfortable

### Mobile rule
Never shrink into a cramped “desktop squeezed into a phone” layout. Mobile must feel intentionally designed.

---

## Accessibility Rules

The interface must remain beautiful and usable.

### Required accessibility behavior
- maintain readable contrast
- keep text clear over translucent backgrounds
- provide obvious focus states
- ensure keyboard accessibility
- ensure form labels are present
- never hide meaning inside decoration only
- provide fallback states when background effects are unavailable

### Transparent surfaces
Glass can be used, but never at the expense of legibility.

### Motion accessibility
Respect reduced-motion preferences:
- minimize animation
- reduce parallax
- simplify entrance transitions
- preserve a stable composition

## Hard Rules

### Never do these:
- use a default dark startup theme
- overuse neon accents
- crowd the page with cards
- make the design look generic
- use heavy shadows everywhere
- rely on plain gray corporate panels
- add unnecessary UI chrome
- make every element equally loud
- abandon whitespace
- make text decorative at the expense of reading

### Always do these:
- preserve airy spacing
- keep a strong focal point
- use glass surfaces intentionally
- let blue / aqua / white dominate
- make the layout feel calm and premium
- make motion feel light and purposeful
- maintain a strong sense of atmosphere
- keep the interface humane and intelligible

---

## Optional Hidden Layer

If desired, include a subtle hidden “system console” or “archive” section behind the main experience.

This should:
- not dominate the homepage
- feel discoverable
- live as a quiet easter egg
- preserve the main elegant direction
- reward curiosity without breaking style

This hidden layer can nod to older systems without becoming the primary visual identity.

## Final Design Intent

The final experience should feel like:

> a luminous ocean of glass interfaces wrapped around a calm, intelligent core

OpceanAI.com should not look like it is trying to compete with every other AI homepage.

It should feel like it belongs to a different lineage:
- cleaner than most retrofuturist sites
- more emotional than pure minimalism
- more refined than skeuomorphic nostalgia
- more atmospheric than a standard product page

It is not just a website.

It is a **visual world for intelligent systems**.
