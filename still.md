# OpceanAI Still.md
## A detailed visual + implementation reference for a Perplexity / Comet / Liquid Glass / Frutiger Aero direction

This document is a **style and build reference** for **OpceanAI.com**.

It is not a brand manifesto only.  
It is a practical map for **layout, spacing, motion, typography, glass materials, atmosphere, and code structure**.

---

## 1) Core design direction

OpceanAI.com should feel like:

- a **calm answer engine**
- a **premium AI browser / research surface**
- a **glass-like interface with ocean depth**
- a **Frutiger Aero-inspired world with light, air, water, and glow**
- a **clean, modern, highly legible product page**
- a site with **very few decisions on first load**
- a page that feels **alive, but never noisy**

The best mental model is:

> **Perplexity calmness + Comet clarity + Liquid Glass material + Frutiger Aero atmosphere**

The result should not look like a generic SaaS homepage.

It should feel like a **living interface for intelligent systems**.

---

## 2) Reference pillars

### 2.1 Perplexity / Comet
Use this as the structure and pacing reference.

What to borrow:
- one dominant hero message
- a central search input
- strong hierarchy
- very large empty space
- minimal navigation density
- a “browse with intelligence” feeling
- content that appears organized, not crowded
- product-first positioning instead of marketing-first noise

**Official references**
- Perplexity homepage: https://www.perplexity.ai/
- Comet browser page: https://www.perplexity.ai/comet/
- Comet getting started page: https://www.perplexity.ai/comet/gettingstarted
- Comet resource hub: https://www.perplexity.ai/comet/resources
- Framer Comet landing page reference: https://www.framer.com/gallery/perplexity-comet

What matters most:
- the hero is not decorative clutter
- the search bar is not an afterthought
- the page feels like a tool, not an ad
- the experience is shaped around **exploration**
- the hierarchy guides the eye in one clean path

---

### 2.2 Liquid Glass
Use this as the material system reference.

What to borrow:
- translucent surfaces
- blur with purpose
- soft refractive edges
- light that appears to travel through surfaces
- a subtle sense of depth
- layers that feel physically stacked
- controls that separate from the background without becoming heavy

**Official references**
- Apple newsroom announcement: https://www.apple.com/newsroom/2025/06/apple-introduces-a-delightful-and-elegant-new-software-design/
- Apple Design gallery: https://developer.apple.com/design/new-design-gallery/
- Apple Liquid Glass documentation overview: https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass
- Apple new design resources: https://developer.apple.com/design/whats-new/

What matters most:
- glass should never become muddy
- blur should remain readable
- highlights should feel directional
- layers should breathe
- glass should be used to focus content, not to hide it

---

### 2.3 Frutiger Aero
Use this as the atmosphere reference.

What to borrow:
- oceanic calm
- sky gradients
- bubbles and small particles
- glossy surfaces
- nature-infused optimism
- soft highlights
- white / aqua / sky-blue palettes
- visual friendliness
- the feeling that technology can be beautiful and gentle

**Reference pages**
- Frutiger Aero overview: https://aesthetics.fandom.com/wiki/Frutiger_Aero
- Frutiger Aero revival / Neo-Aero: https://aesthetics.fandom.com/wiki/Neo-Aero
- Web Design Museum golden age archive: https://www.webdesignmuseum.org/golden-age-of-web-design
- Web Design Museum gallery examples: https://www.webdesignmuseum.org/gallery/space-jam-1996

What matters most:
- lightness
- air
- blue water gradients
- soft green accents
- glossy but not plastic
- a hopeful tone, not a corporate sterile tone

## 3) What OpceanAI.com should feel like

The site should feel like:

- a calm lake with intelligent layers underneath
- a browser for ideas
- a place that can answer, explore, and connect
- a polished product page with emotional softness
- a futuristic surface that does not try too hard
- a premium homepage that feels slightly utopian

The emotional target is:

> **smart, calm, luminous, breathable, and trustworthy**

Not:
- loud
- crowded
- dark and aggressive
- “crypto dashboard”
- overdesigned
- generic startup gradients with random blobs

---

## 4) Visual composition rules

### 4.1 Hero structure
The hero should be built around 4 layers:

1. **Background atmosphere**
   - sky / ocean gradient
   - soft radial light
   - small floating particles
   - faint blurred circles

2. **Top navigation**
   - very small
   - very light
   - aligned to the edge
   - almost background-like

3. **Main message**
   - large title
   - short subtitle
   - one paragraph max
   - strong breathing room around it

4. **Primary interaction**
   - a search field or command field
   - one primary action button
   - one secondary action button

The page should never begin with too many choices.

---

### 4.2 Spacing rhythm
Use an airy system.

Recommended feel:
- generous vertical padding
- content centered with clear breathing room
- wide margins on desktop
- layered separation rather than boxed sections
- big blocks of negative space

Spacing should make the page feel:
- calm
- premium
- deliberate
- easy to scan

Suggested rhythm:
- section gap: large
- card gap: medium
- text gap: small to medium
- title-to-body gap: medium
- body-to-actions gap: medium

---

### 4.3 Corners and surfaces
Use rounded geometry everywhere.

Preferred feel:
- soft rounded corners
- translucent card edges
- glass panels with subtle glow
- no hard black borders
- no sharp angular aggression

Surface layers should look like:
- floating panels
- softly embedded controls
- clear but delicate containers

---

## 5) Color system

### 5.1 Base palette
The core palette should live inside:
- sky blue
- ice blue
- aqua
- mint
- pale white
- deep ocean blue for text or emphasis
- very soft silver-gray for secondary UI

### 5.2 Suggested palette direction
- Background top: pale sky blue
- Background mid: light aqua-blue
- Background bottom: deeper ocean blue
- Primary text: deep navy / ocean blue
- Secondary text: muted blue-gray
- Accent: aqua / mint / bright but soft cyan
- Glow: translucent white-blue

### 5.3 Rules
Do not overuse:
- pure black backgrounds
- pure neon green
- harsh saturated red
- muddy gray blocks
- overly dark mode styling
- corporate beige

The page should look bright, breathable, and slightly aquatic.

---

## 6) Typography system

### 6.1 Main type behavior
Typography should feel:
- modern
- calm
- highly readable
- soft in weight
- not too geometric
- not overly futuristic

### 6.2 Suggested font mood
For the product face:
- Inter
- SF Pro style feel
- Segoe UI style feel
- Avenir-like warmth

For the “Frutiger Aero” side of the system:
- slightly rounded UI text
- clear spacing
- friendly forms
- subtle optical softness

### 6.3 Size hierarchy
A useful hierarchy:

- Hero title: very large
- Subhead: medium-large
- Body: comfortable reading size
- Labels / pills / nav: small but readable
- Meta text: quiet and restrained

### 6.4 Typography rules
- avoid condensed fonts
- avoid harsh monospace as the primary face
- avoid ultra-light text for important content
- keep line-height generous
- keep paragraph width controlled
- do not let text stretch edge-to-edge on wide screens

---

## 7) Motion and interaction

Motion should feel:
- slow
- liquid
- intentional
- atmospheric
- soothing
- useful

### 7.1 Background motion
Good motion ideas:
- drifting particles
- subtle bubble rise
- moving highlight across glass surfaces
- soft parallax between background layers
- slight ocean-wave movement
- slow radial light bloom

### 7.2 Micro-interactions
Use movement for:
- hover states
- focus states
- nav transitions
- button reflections
- search bar expansion
- card depth changes

### 7.3 Motion rules
- no bouncy cartoon motion
- no aggressive overshoot
- no chaotic parallax layers
- no constant high-speed animation
- no attention-stealing transitions

Motion should support calmness, not destroy it.

---

## 8) Layout patterns

### 8.1 Home page layout
Recommended structure:

- top navigation
- hero badge / eyebrow
- large title
- supporting subtitle
- search or command input
- primary / secondary actions
- featured project list
- explanation section
- deep links / docs / system / about
- footer with quiet metadata

### 8.2 Section behavior
Each section should:
- have a clear purpose
- use enough spacing to breathe
- introduce one idea at a time
- avoid multi-column chaos unless necessary
- keep visual density low

### 8.3 Card behavior
Cards should:
- be translucent
- feel layered
- show depth
- have soft highlights
- never look like basic rectangle panels

---

## 9) Search bar / command bar system

This is a crucial centerpiece.

It should feel like:
- Perplexity’s search field
- Comet’s action surface
- a calm launcher for knowledge
- a place to enter intent, not just keywords

The input should:
- be large enough to be inviting
- have a soft glass background
- show a subtle icon
- support placeholder copy that feels curious and human
- look like the starting point of the whole site

Examples of suitable placeholders:
- What would you like to explore?
- Ask OpceanAI anything
- Search projects, docs, or systems
- Explore intelligent surfaces

The input should behave like:
- a search
- a command launcher
- an entry into the OpceanAI ecosystem

---

## 10) Navigation style

Navigation should be extremely restrained.

Ideal top nav:
- Projects
- Docs
- System
- About

Optional:
- Resources
- Labs
- Contact

Navigation rules:
- keep it small
- keep it aligned cleanly
- keep it visually subordinate to the hero
- avoid large menu bars
- avoid excessive nested navigation
- avoid dropdown clutter unless it is truly needed

---

## 11) Component library direction

### 11.1 Glass button
Buttons should:
- be soft
- slightly translucent
- have a light border
- include hover glow
- feel touchable
- avoid heavy shadows

### 11.2 Glass card
Cards should:
- float above the background
- have clear but delicate edges
- carry a reflective surface
- remain readable in all states
- avoid opaque blocks

### 11.3 Badge / pill
Badges should:
- feel like floating labels
- use tiny text
- have a gentle fill
- look like a luminous tag or signal

### 11.4 Divider
Dividers should:
- be almost invisible
- use gradients instead of hard lines
- feel like air breaks, not walls

## 12) Implementation notes for CSS / code

This section gives the practical engineering shape.

### 12.1 Background
Use layered CSS backgrounds:
- radial gradients
- linear gradients
- noise overlay
- faint blur circles
- moving light bloom
- subtle particle canvas or SVG layer

### 12.2 Glass effect
A strong liquid-glass surface usually needs:
- semi-transparent fill
- backdrop blur
- soft border
- inner highlight
- faint shadow
- slightly brighter top edge

### 12.3 Depth
Depth should come from:
- layered translucency
- blur
- contrast control
- light direction
- shadow softness
- scale changes on hover

### 12.4 Accessibility
Even when the site is beautiful:
- text must remain readable
- contrast must stay acceptable
- keyboard focus must be visible
- motion must respect reduced-motion preferences
- the interface must still make sense without the special effects

## 13) Example code patterns

These are **original implementation patterns**, not copied from any source.

### 13.1 Liquid glass panel
```css
.glass-panel {
  background: rgba(255, 255, 255, 0.18);
  backdrop-filter: blur(22px) saturate(140%);
  -webkit-backdrop-filter: blur(22px) saturate(140%);
  border: 1px solid rgba(255, 255, 255, 0.28);
  box-shadow:
    0 12px 40px rgba(0, 60, 120, 0.12),
    inset 0 1px 0 rgba(255, 255, 255, 0.35);
  border-radius: 28px;
}
```

### 13.2 Frutiger Aero atmosphere background
```css
.hero-background {
  background:
    radial-gradient(circle at 50% 20%, rgba(255,255,255,0.75), transparent 28%),
    radial-gradient(circle at 20% 35%, rgba(140, 240, 255, 0.30), transparent 22%),
    radial-gradient(circle at 80% 55%, rgba(120, 210, 255, 0.22), transparent 18%),
    linear-gradient(180deg, #e8f9ff 0%, #9ddcf4 48%, #5ab1df 100%);
}
```

### 13.3 Calmer hero spacing
```css
.hero {
  min-height: 100vh;
  display: grid;
  place-items: center;
  padding: 96px 24px 72px;
}
```

### 13.4 Search field
```css
.search-bar {
  width: min(760px, 100%);
  display: flex;
  align-items: center;
  gap: 12px;
  padding: 16px 18px;
  border-radius: 999px;
}
```

### 13.5 Hover behavior
```css
.glass-panel:hover {
  transform: translateY(-2px);
  border-color: rgba(255, 255, 255, 0.38);
  box-shadow:
    0 18px 50px rgba(0, 60, 120, 0.16),
    inset 0 1px 0 rgba(255, 255, 255, 0.42);
}
```

## 14) Design anti-patterns

Do not introduce:
- dark enterprise dashboards
- random neon gradients
- cluttered stacks of cards
- large blocks of text with no breathing room
- overdone glass that kills contrast
- too many shadows
- too many borders
- retro OS gimmicks if the goal is the clean OpceanAI homepage
- generic AI landing clichés

Avoid anything that makes the page feel:
- cheap
- busy
- cold
- loud
- noisy
- visually exhausted

## 16) Implementation stack guidance

A good stack for this visual direction:
- Next.js
- TypeScript
- Tailwind or CSS modules
- Framer Motion for soft motion
- SVG or Canvas for particles
- lightweight custom glass components

Keep the stack modern, but never let the stack leak into the visual tone.

The user should feel the surface, not the framework.
